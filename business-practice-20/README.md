# 20 business workflow practice cards / 20个业务工作流练习

A free FORMWEFT learning collection with **20 distinct tasks**, fictional inputs, copyable bilingual requests, expected review decisions and a variation to try. These are authored exercises, not results from customer projects or live AI evaluations.

这套免费资料包含 **20 个不同业务场景**：每份都附虚构输入、可复制中英请求、预期答案和变式。可用来检查 AI 输出是否保留出处、遗漏资料和人工决定。它们是练习资料，不是现成功能，也不代表客户成绩。

## Start in ten minutes / 十分钟开始

1. Pick one card close to your work. 选择一个最贴近日常工作的场景。
2. Copy only its task, sample inputs and request into an AI tool you already use. 不要同时复制预期答案。
3. Compare its output with the authored answer key. 先核对事实与处理决定，再看文字表达。
4. Try the changed input and save the review record. 尝试变式，记录错误与人工修改。
5. Use permitted or fictional data when adapting the exercise. 接入真实数据或系统前，另外设计权限、验证与回退。

No signup is required to read or download this collection. Any external AI tool has its own access requirements and charges. No live workflow is connected by these Markdown files.
